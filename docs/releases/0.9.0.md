# BillieWeather 0.9.0

Stable uses the hosted BillieWeather Rails and Identity services. Email registration verifies
the mailbox before account creation. Existing users can sign in with email and password.
Google sign-in is available only when the service has OAuth configured.

BillieWeather Dev has its own app identity, local ledger and credentials. It connects to
loopback development services backed by the independent Development PostgreSQL project.

The local ledger remains SQLite. The installer checks the current ledger and preserves a
recoverable app and database backup before updating.
